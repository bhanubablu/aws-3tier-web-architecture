🚀 Excited to share my latest Cloud & DevOps project: **Highly Available 3-Tier Web Application Architecture on AWS** built entirely using **Terraform (Infrastructure as Code)**!

As a Cloud & DevOps engineer, designing for high availability, fault tolerance, and security is priority #1. In this project, I built a production-style architecture following the AWS Well-Architected Framework:

🔹 **Network Security & Isolation:** Custom VPC with 6 subnets across 2 Availability Zones. Strict separation of public web, private app, and isolated database tiers.
🔹 **High Availability & Zero Downtime:** Application Load Balancer (ALB) and Auto Scaling Group (ASG) dynamically scaling EC2 instances based on traffic demand.
🔹 **Database Durability:** Multi-AZ Amazon RDS (MySQL) in dedicated private subnets with automatic failover and daily snapshots.
🔹 **Least-Privilege Security:** Fine-grained AWS Security Groups ensuring only ALB can speak to EC2, and only EC2 can talk to RDS (no public internet access to database).
🔹 **Observability:** Custom CloudWatch alarms for CPU utilization and ALB 5XX error tracking.
